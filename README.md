A simple Pong Clone made in C with the Raylib framework.
Install the raylib framework to compile and run the pong.c main game file.

Project isn't completed yet, to play the latest prototype, compile and run the .c file or execute the latest executable (pongStage1).

Proper user support for full screen not added yet, for the optimal experience, play the game in the same sized window as it opens.

Press 'r' to replay the game upon game over.

WASD keys move the left bar, whereas the arrow keys move the right bar. 

Can be easily played with a friend on the same pc.
